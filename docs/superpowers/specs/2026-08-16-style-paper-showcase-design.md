# Style-mimic 多文风论文展示设计规格

## 目标

制作一个可离线打开的静态网页，并交付一份本地编译成功的 LaTeX PDF。两者展示同一篇关于 `style-mimic` 框架的论文，用 11 种文风改写同一组语义骨架：苏轼、桐城派、王勃、鲁迅、胡适、钱钟书、Barbara Oakley、Donald Trump、Barack Obama、Albert Einstein、Richard Feynman。

所有版本都明确标记为教学仿写，不声称作者本人创作，也不把风格分数当作作者身份判定。

## 内容结构

论文固定为五个语义单元，确保跨文风可比：

1. 摘要：问题、方法、主要发现；
2. 方法：六层风格画像、差分基线、尾部统计和 review 工具；
3. 案例：同一段 style-mimic 说明在不同声纹下的表达；
4. 限制：短文本、不确定性、体裁效应、活人作者伦理；
5. 结论：风格是可测分布，不是单一标签。

每个版本保留相同的事实与论点，只改变词汇、句法节奏、修辞、立场介入、叙事声音和段落推进。中文作者使用中文变体；英文作者使用英文变体，并在网页中统一展示中文译题和英文原文。

## 网页方案

采用零构建依赖的 `index.html` + `styles.css` + `app.js` + `data/styles.json`：

- 首屏用一句论文主张作为标题，并显示 11 个风格版本的总览统计；
- 左侧/顶部为风格筛选，支持语言、时代、文体标签；
- 主内容按五个语义单元切换，提供“同一单元多声部”并排阅读；
- 每张卡片显示作者标签、仿写声明、句长/AI 味/相似度等已实际运行的指标；
- 提供“复制当前段落”和“打开 PDF”两个明确动作；
- 键盘焦点、移动端布局、`prefers-reduced-motion` 和空状态均有处理；
- 不依赖外部 CDN，保证离线可用。

视觉方向是“文体实验室”：深墨黑作为底色，纸张白作为阅读面，单一朱砂色作为选中态；标题使用高对比衬线字体，数据使用等宽字体。签名元素是一个“同一命题 / 多个声部”的横向声纹轨迹，而不是通用渐变 Hero。

## LaTeX 方案

文件放在 `examples/style-paper/tex/`：

- `style-mimic-paper.tex`：主文档；
- `styles.tex`：颜色、定理框、风格版本环境等宏；
- `references.bib`：框架与 AI 写作研究文献；
- `style-mimic-paper.pdf`：本地编译产物。

优先使用 `xelatex`，中文字体采用本机可用字体探测结果；若字体不可用，提供英文 fallback 并在编译日志中记录。编译至少运行两次，检查交叉引用、目录、页数和 PDF 文本可提取性。

## 数据流

```text
style corpus / profiles
        ↓
styles.json（共享语义单元、文风正文、指标）
        ├── app.js → 静态网页
        └── 生成/同步 → LaTeX 章节
```

网页和 PDF 的正文必须来自同一份结构化数据；如果 LaTeX 为排版需要做少量转义，只允许在生成层处理，不手工维护第二份正文。

## 验收标准

### 内容

- 11 个版本全部存在，作者、语言、时代和伦理标签完整；
- 同一语义单元在各版本之间可逐项对照；
- 不把活人作者版本写成“原作”或“官方风格”。

### 网页

- 直接静态打开或通过 `python3 -m http.server` 可用；
- 筛选、单元切换、复制按钮、PDF 链接有效；
- 移动端和键盘操作不破坏阅读；
- 浏览器控制台无未处理错误。

### LaTeX/PDF

- `xelatex` 或明确记录的 fallback 编译命令成功；
- PDF 文件实际存在、页数大于 1、文本可提取；
- 论文正文、附录和引用均进入 PDF；
- 网页中的当前版本与 PDF 中对应章节一致。

### 风格工具验收

- 对每个版本运行 `style_analyze.py`；
- 对代表性版本运行 `style_review.py aiflavor` 和 `sim`；
- 把实测结果写入网页和论文附录，并声明启发式边界。

## 不做的事

- 不调用外部模型自动生成正文；
- 不把风格分数包装为 AI 检测或作者身份识别；
- 不引入 React/Vite 等构建系统；
- 不为了“像”而复制受版权保护的长段落，样本只用于提取风格特征。
