# Shared paper data

`styles.json` is the single prose source for the web showcase and the LaTeX
paper. Every voice keeps the same five semantic units and changes only the
language/register choices. The content is original teaching pastiche; it is not
copied source text and does not claim authorial authenticity.

The `metrics` field is added after running the repository's analysis scripts.
It contains rounded review signals for navigation and comparison, not
authorship or AI-generation judgments.
